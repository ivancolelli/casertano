# Casertano MX

Restaurant website concept built with React and Vite.

The project was designed to create a modern digital presence for a food business, focusing on responsive layouts, visual storytelling and user experience.

## Technologies

- React
- Vite
- JavaScript
- HTML5
- CSS3

## Features

- Responsive website layout
- Mobile-first design
- Modern UI components
- Optimized frontend structure
- Fast development using Vite

## Live Demo

https://casertanomx-no-official.netlify.app

## Purpose

This project demonstrates the development of a modern restaurant website using current frontend technologies, focusing on design, usability and performance.
